# My Speckit Project

This project follows the Github Speckit methodology for AI-assisted development.

## Directory Structure

- `specs/` - Specification documents (Step 1: Specify)
- `docs/` - Planning and architecture documents (Step 2: Plan)
- `tasks/` - Task breakdown files (Step 3: Tasks)
- `src/` - Implementation code (Step 4: Implement)

## Workflow

1. **Specify**: Define what to build in `specs/`
2. **Plan**: Determine tech stack and architecture in `docs/`
3. **Tasks**: Break down into manageable tasks in `tasks/`
4. **Implement**: Build the application in `src/`

## Getting Started

See the specification documents in `specs/` to understand the project requirements.
