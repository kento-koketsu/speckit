## 概要

マコなり社長の名言・格言ジェネレーターは、ユーザーがボタンをクリックするだけでマコなり社長の感銘的な名言をランダムに表示するWebアプリケーションです。シンプルで直感的なインターフェースを通じて、ユーザーに即座に感銘とモチベーションを提供することを目的としています。

このアプリケーションは、1ページ完結型のシングルページアプリケーション（SPA）として設計され、最小限のインタラクションで最大限の価値を提供します。

## ユーザーストーリー

### 主要ユーザーストーリー
1. **モチベーションを求めるユーザーとして**、ボタンを1回クリックするだけで感銘的な名言を見て、日々の活力を得たい
2. **マコなり社長のファンとして**、様々な名言をランダムに閲覧して、新しい気づきや学びを得たい
3. **モバイルユーザーとして**、スマートフォンからでも快適に名言を閲覧して、いつでもどこでもモチベーションを得たい

## 機能要件

### 必須機能（MUST）
1. **ランダム名言表示機能**
   - ボタンクリックで名言データベースからランダムに1つの名言を選択して表示
   - 直近5件の重複防止はメモリ内のみで管理（ページリロード時にリセット）
   - 名言テキストは読みやすいタイポグラフィで中央配置
   - 著者名「マコなり社長」のみ表示（出典情報は非表示）

2. **名言ボタンUI**
   - 目立つ位置に配置された「次の名言」ボタン
   - クリック時の視覚的フィードバック（アニメーション、色変化等）
   - キーボードナビゲーション対応（Enterキー、スペースキー）

3. **レスポンシブデザイン**
   - 320px〜1920pxの画面幅に対応
   - モバイル、タブレット、デスクトップで最適化されたレイアウト
   - 縦向き・横向き両対応

4. **パフォーマンス最適化**
   - 詳細は「非機能要件 > パフォーマンス」を参照
   - 初期ロード、バンドルサイズ、レスポンス時間の要件を満たすこと

### 推奨機能（SHOULD）
1. **アニメーション効果**
   - 名言切り替え時のフェードイン/アウト
   - ボタンホバー時の視覚効果

## 非機能要件

### パフォーマンス
- **初期ページロード**: 2秒以内（3G接続、Lighthouse Performance Score 90以上）
- **Time to Interactive (TTI)**: 3秒以内
- **First Contentful Paint (FCP)**: 1.5秒以内
- **名言生成レスポンス**: 50ms以内（内部処理）、100ms以内（体感）
- **バンドルサイズ**: 100KB以下（gzip圧縮後）

### セキュリティ
- **XSS対策**: すべてのユーザー入力（該当する場合）をサニタイズ
- **HTTPS**: 全通信をHTTPS経由で行う
- **CSP**: Content Security Policyヘッダーの適用
- **依存関係**: 既知の脆弱性がないライブラリのみ使用
- **データ保護**: 個人情報は収集しない

### 互換性
- **ブラウザサポート**:
  - Chrome 90+
  - Firefox 88+
  - Safari 14+
  - Edge 90+
  - モバイルSafari (iOS 14+)
  - Chrome for Android (最新版)
- **デバイス**: デスクトップ、タブレット、スマートフォン
- **画面サイズ**: 320px〜1920px幅
- **OS**: Windows 10+、macOS 11+、iOS 14+、Android 10+

### インタラクションフロー
1. **初回ロード**
   - ページロード時にランダムな名言を自動表示
   - ローディングインジケーター表示（必要に応じて）

2. **名言の切り替え**
   - ユーザーが「次の名言」ボタンをクリック
   - ボタンにクリックフィードバック（押下アニメーション）
   - 現在の名言がフェードアウト
   - 新しい名言がフェードイン表示
   - ボタンが再度クリック可能状態に

## データモデル

### エンティティ

- **Quote（名言）**
  - `id`: string（一意識別子）
  - `text`: string（名言本文、必須、1〜500文字）
  - `author`: string（「マコなり社長」固定）
  - `date`: string（任意、内部管理用、YYYY-MM形式、表示には使用しない）
  - `source`: string（任意、内部管理用、表示には使用しない）
  - `context`: string（任意、内部管理用、表示には使用しない）

### データ構造例（JSON）

```json
{
  "quotes": [
    {
      "id": "quote-001",
      "text": "行動しない人に成功はない。小さくてもいいから、今日から動き出そう。",
      "author": "マコなり社長",
      "date": "2024-01",
      "source": "YouTube: ビジネスで成功する秘訣",
      "context": "起業初期の心構えについて"
    }
  ]
}
```

## API仕様（該当する場合）

本アプリケーションは完全にクライアントサイドで動作するため、外部APIは不要です。名言データは静的JSONファイルまたはJavaScriptモジュールとしてバンドルされます。

## 技術制約

### 依存関係
- **必須**: なし
- **採用技術**:
  - **JavaScript**: Vanilla JavaScript（フレームワークなし）
  - **CSS**: ピュアCSS（フレームワークなし）
  - **ビルドツール**: Vite

### 制限事項
- 名言データは静的ファイルとして管理（初期は50〜100件程度）
- データベースは使用しない（静的サイトとしてデプロイ）
- バックエンドAPIは不要
- 名言の総データサイズは50KB以下
- 重複防止履歴はメモリ内のみ保持（localStorageは使用しない）

## テスト戦略

### 受け入れ基準
- [x] ページロード時にランダムな名言が表示される
- [ ] 「次の名言」ボタンをクリックすると新しい名言が表示される
- [ ] 連続でクリックしても同じ名言が表示されない（直近5件は重複しない）
- [ ] モバイルデバイス（iPhone、Android）で正常に動作する
- [ ] キーボードのEnterキーでボタンを操作できる
- [ ] スクリーンリーダー（VoiceOver、NVDA）で名言を読み上げられる
- [ ] ページロードが2秒以内（3G接続シミュレーション）
- [ ] Lighthouse Performance Score 90以上
- [ ] Lighthouse Accessibility Score 100
- [ ] 色覚障がい者向けカラーコントラストチェック合格

### テストケース

1. **名言ランダム表示テスト**
   - 前提条件: ページ未ロード
   - 手順: ページにアクセス
   - 期待結果: 名言がランダムに1つ表示される

2. **名言切り替えテスト**
   - 前提条件: 名言が表示されている
   - 手順: 「次の名言」ボタンをクリック
   - 期待結果: 異なる名言が表示される

3. **重複防止テスト**
   - 前提条件: 名言データが10件以上存在
   - 手順: ボタンを連続で5回クリック
   - 期待結果: 直近5件で同じ名言が表示されない

4. **レスポンシブデザインテスト**
   - 前提条件: ブラウザDevToolsのデバイスモード
   - 手順: 画面幅を320px、768px、1920pxに変更
   - 期待結果: すべての幅で読みやすく表示される

5. **キーボード操作テスト**
   - 前提条件: マウスを使用しない
   - 手順: Tabキーでボタンにフォーカス、Enterキーで実行
   - 期待結果: 新しい名言が表示される

6. **スクリーンリーダーテスト**
   - 前提条件: VoiceOverまたはNVDA有効
   - 手順: ページを読み上げる
   - 期待結果: 名言テキストとボタンが適切に読み上げられる

7. **パフォーマンステスト**
   - 前提条件: Chrome DevToolsのネットワークスロットリング（Fast 3G）
   - 手順: Lighthouseでパフォーマンス測定
   - 期待結果: スコア90以上

## リスクと対策

| リスク | 影響度 | 発生確率 | 対策 |
|--------|--------|----------|------|
| 名言データの著作権問題 | 高 | 中 | 公開発言からの引用であることを明記、必要に応じて許諾取得 |
| モバイルブラウザでのパフォーマンス問題 | 中 | 中 | 徹底的な最適化、バンドルサイズ削減、遅延ロード |
| アクセシビリティ基準未達 | 中 | 低 | 開発初期からWCAG準拠、専門家レビュー実施 |
| 名言データの管理コスト | 低 | 高 | シンプルなJSON形式、バージョン管理で履歴保持 |
| 低速ネットワークでのロード遅延 | 中 | 中 | CDN利用、アセット最小化、Service Workerによるキャッシュ |
| ブラウザ互換性問題 | 低 | 低 | モダンブラウザのみサポート、Polyfillの最小限使用 |
